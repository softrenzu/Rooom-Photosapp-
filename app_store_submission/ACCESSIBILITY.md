# Accessibility Nutrition Labels

The following support can be selected after a final pass on a physical iPhone:

| Feature | Intended answer | Evidence |
|---|---|---|
| VoiceOver | Supports | Camera button has a label and hint; status is available as text and icon; controls use native SwiftUI labels |
| Voice Control | Supports | Interactive controls use native buttons and labeled fields |
| Larger Text | Supports | System fonts and Dynamic Type are used throughout |
| Dark Interface | Supports | The app uses an intentional dark interface with system materials |
| Differentiate Without Color Alone | Supports | Upload states use text and distinct symbols in addition to color |
| Sufficient Contrast | Supports | White primary text and high-contrast controls are used on the brand gradient |
| Reduced Motion | Supports | Motion is decorative and brief; core actions do not depend on it |
| Captions | Not applicable | No spoken video |
| Audio Descriptions | Not applicable | No video content |

Do not select a label until the corresponding behavior is confirmed on the signed TestFlight build.
